# TIDE Project Website

Static showcase website for **TIDE — Trasferimento tecnologico Intelligente per il Digital hEalth**.

The site is designed for GitHub Pages and does not require a backend.

## Files

- `index.html` — full website structure and content
- `style.css` — responsive visual design
- `assets/` — optional logos, photographs and project files

## Publish on GitHub Pages

1. Create a GitHub repository (for example `tide-project`).
2. Upload `index.html`, `style.css` and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment** choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save.

The website will become available at:

```text
https://YOUR-USERNAME.github.io/tide-project/
```
